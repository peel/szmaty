# Szmaty — mapa pojemników w Gdańsku

Mapa zawiera 214 opisów lokalizacji z 227 wpisów źródłowych: 130 dopasowanych adresów, 77 lokalizacji orientacyjnych i 7 bez współrzędnych. Nie potwierdza aktualnej obecności pojemników.

Współrzędne zapisano bezpośrednio w `index.html`; kopia danych znajduje się w `gdansk_punkty.json`. Mapa nie pobiera współrzędnych przy uruchomieniu. Dostęp do internetu jest potrzebny do podkładu OpenStreetMap.

Źródło wykazu: https://s-trojmiasto.pl/download/pojemniki-pomorskie.pdf (wiersze 219–445, strony 4–7).
